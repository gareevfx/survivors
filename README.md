# Survivors

A browser RTS. Run with `npm install` then `npm run dev`. Serves on http://127.0.0.1:4317/.

Computer sides in 1 vs 1 and free-for-all, and the `ai control` command, all use SiloAI. It gathers Dumps, raises Storage, a Factory, and Pillars, keeps Hovers scouting, and attacks the enemy Silo. When the Dumps beside its Silo run out, it builds a Storage beside the next Dumps heap it has seen.
